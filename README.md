# Irish Quiz

## Overview

This project was developed as part of the Client-Side Web Development module during the first year of the BSc Computing Science degree at Griffith College.

The application is an interactive quiz focused on Irish culture and general knowledge. Users can answer multiple questions, navigate through the quiz, and receive a final score based on their performance.

## Features

- Interactive quiz interface
- JavaScript-based question handling
- Score calculation
- User feedback and results
- Navigation controls
- Image integration
- Responsive web design

## Technologies Used

- HTML5
- CSS3
- JavaScript
